# Supaworld

A static website for creating and managing Supabase projects that run inside the browser, powered by [supa-wasm](https://github.com/supabase/supa-wasm).

The planned application uses **Svelte, Vite, TypeScript, shadcn-svelte, and Tailwind CSS**. PostgreSQL and the Supabase services run in Web Workers; project data stays in browser storage.

Phase 1 covers multiple saved projects, switching, renaming, deletion, a small database workspace, and backup/restore. PWA installation and offline support are an optional final milestone. Application hosting and the full development environment belong to phase 2.

Read the [detailed phase 1 plan](docs/phase-1-plan.md) for scope, architecture, upstream constraints, milestones, and acceptance criteria.

**Status:** planning only. This repository does not contain an application implementation yet.
